## 因子值文件

长表格式，可用 pandas / pyarrow 直接读：

```python
import pandas as pd
df = pd.read_parquet("data/f5_ts60_vol60_20260828_signal.parquet")
# instrument(str) | trade_date(str) | factor(float32) | status(str)
```

1,683,032 行，1170 只股票，2018-01-02 至 2026-07-31，**日频**（不只调仓日）。
`status == "invalid"` 表示该格无有效值（非成分股、停牌、或滚动窗口尚未就绪）。

**用 `signal` 做绩效复核，用 `raw` 做中性化方案的重新试验**——raw 与所有下游选择无关，
换中性化窗口或平滑天数只需在 raw 上重算，是秒级操作，不必重跑分钟层。

## 已知问题（请重点看这几条）

1. 验证期（2023–24）明确失效：RankIC +0.0042、扣费 −15.3%、毛多空 −8.1%。该段疲软自最早配置起一路延续，与调参无关，但意味着存在整年失效的可能。

2. 样本期起点 2018-01-02 即数据边界，实际预热 0 日，开头约 12 周被 60 日波动率的 NaN 前缀截掉，全期 418 周而非 420 周。

3. 矩阵内同一行各格的收益差别多为噪声（沿波动率窗口非单调）；可信的是跨行比较，即 ts_std 60 优于 50 这一结论，它不依赖任何单格。

4. WINDOWS 已加入 60，但 window=60 尚未做成本标定，3 项标定测试为红。报告与回测不受影响，重跑 v7 前须执行 python -m min_gp.benchmark_seed_operators。

## 流程审计

已做五项机械检查，共 16/16 项通过，原始结果在 `audit/`：

1. **未来函数** — 抹掉第 t 列之后的全部数据重算，第 t 列及之前逐位不变（4 个切点全为 0）。
   并附反证：故意注入 3 日前视后同一检查立刻报警，证明它不是永远通过的空检查。
2. **数据对齐** — 收盘价逐格对齐原始 parquet；标签逐格等于 `close[t+1周]/close[t]−1`。
3. **股票池** — 成分掩码逐格对齐 PIT 名单；首末成分差异率 57.3%（无幸存者偏差）；
   池外单元格中信号非 NaN 的有 0 个。
4. **因子预处理** — MAD5 确实按中位数绝对偏差截尾；中性化后残差与暴露相关 <1e-8；
   10 日平滑与手算逐位一致。
5. **IC 计算** — 与 `scipy.stats.pearsonr` / `spearmanr` 对账，差异在 1e-16 / 1e-9 量级；
   错期配对给出不同值，证明配对有效。

审计在验证期（2023-01 至 2024-12，733 只 × 564 日 × 241 分钟）上执行，
所测逻辑不随窗口变化。
